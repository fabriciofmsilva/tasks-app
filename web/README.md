# web

Frontend of [tasks-app](../README.md) — Next.js (App Router, TS).

## Run locally

```bash
npm run dev
```

Open at [http://localhost:3000](http://localhost:3000).

## Pages

```
/               ← Home
/about          ← SSG
/(auth)/signup  ← Dynamic (close to SSR)
/(auth)/login   ← Dynamic (close to SSR)
/(auth)/logout  ← Dynamic (close to SSR)
```

## Status

Work in progress: public landing page, fake login/signup, and a task dashboard.
